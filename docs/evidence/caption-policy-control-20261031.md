## Implemented boundary

An existing continuous Key camera policy can preview and explicitly confirm
metered captions or a configuration-compatible local unmetered override. Nothing
is selected implicitly. Bypassing the global 12-reservation rolling-hour limit
requires a separate unchecked acknowledgement that local routing does not prove
free inference. A remote route remains refused by the unchanged validator. No
continuous policy, one-use scope conversion, camera scope or provider/secret edit
is synthesized by this page.

The typed store writes only `worker.continuous.unmetered` (true or removed),
preserving other raw fields and omissions. It checks revision, existing identity,
search and credential-route guards, archives prior bytes privately, replaces
atomically and verifies read-back. An unchanged policy retains exact bytes and
revision. The budget journal is not read, changed, refunded or repaired, and a
fresh preview/acknowledgement is required to change the cost policy again. The
form creates no provider Undo for an implicit bypass; existing general admin
configuration/restore authority remains separate.

At most 32 one-use previews are bound to session digest, revision, resulting
revision and ten-minute monotonic expiry. Another save, a foreign session,
revocation/expiry during awaited reads, replay, malformed/duplicate/unknown fields
and a missing bypass acknowledgement refuse before save admission. Registry
capacity does not evict valid previews. After admission, the existing file owner
survives a disconnected waiter and is drained during normal cleanup. An uncertain
acknowledgement retains possible committed state and never automatically retries,
rolls back or resets usage. No provider credential/raw cookie is stored in grants.

The responsive HTML and saved-status JSON remain on the existing authenticated
listener with the same CSRF/origin, private-page and global request-admission
policies. Audit records use a fixed action/result only, not selected values or
private paths. There is no processor start/restart, live configuration reload,
model/media/controller request, new key/file reference or additional dependency.
